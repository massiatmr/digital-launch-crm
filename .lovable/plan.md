# Adapter les noms dans les messages WhatsApp

## Comportement
- Utiliser un prénom ou nom court au lieu du nom complet dans les modèles, relances, rappels et scripts WhatsApp.
- Conserver les accents et l’écriture arabe ; préserver les prénoms composés identifiables et éviter de répéter un nom dans plusieurs alphabets.
- Pour un nom de société ou un nom ambigu, utiliser une formule neutre sans inventer de prénom.
- Ne pas modifier le nom enregistré dans la fiche du lead ni les textes saisis manuellement.

## Détails techniques
- Centraliser la résolution du nom de salutation et l’utiliser dans les substitutions de variables et les consignes de génération IA, y compris les campagnes.
- Vérifier les cas français, arabes, mixtes, prénoms composés, noms de société et noms manquants avec des tests ciblés.
- Déployer les fonctions WhatsApp concernées sans déclencher d’envoi de test aux contacts.
