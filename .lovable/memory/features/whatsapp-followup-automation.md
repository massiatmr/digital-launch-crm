name: WhatsApp followup automation
description: Système de tâches/relances automatiques par lead + IA Lovable + état conversation + déclencheur filtré
type: feature
---
Couche additive (n'altère pas pipeline/leads). Tables: `lead_followup_tasks`, `whatsapp_messages`, `lead_conversation_state`, `followup_automation_settings` (+ colonnes `trigger_sources lead_source[]` défaut `{facebook}` et `trigger_only_new_status bool` défaut true). Trigger SQL `create_followup_sequence_for_lead` (AFTER INSERT sur leads) génère 6 tâches **uniquement si** : auto activée + (status='new' OU filtre désactivé) + lead.source ∈ trigger_sources. Trigger `handle_inbound_whatsapp` annule les relances futures dès qu'un message inbound arrive et bascule l'état à QUALIFIED. Edge functions: `generate-followup-message` (Gemini Flash), `execute-followup-task` (1 tâche), `process-followup-tasks` (batch via pg_cron chaque minute), `preview-template-message` (preview IA des variables). UI `/settings/automation` : 4 onglets (Séquence visuelle / Templates / Brief IA / Réglages). Onglet Réglages contient : dry-run toggle, on/off auto, **carte "Conditions de déclenchement"** (toggle status=new + checkboxes sources), carte "Déclencheur & exécution" (status cron + bouton Exécuter maintenant). Composant `FollowupTimeline` sur fiche lead. **WhatsApp Meta non encore branché** : `execute-followup-task` log les sorties avec status='logged_only'.
